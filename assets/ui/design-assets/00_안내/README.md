# 가치고치 에셋

- 폴더(목차)는 한글, 파일명은 영문이에요. **코드에서는 파일명으로만 찾아 주세요.** 파일명은 모두 달라서 폴더를 바꾸거나 한곳에 모아도 깨지지 않아요.
- `@2x` = 도트 1칸이 2px(앱 기본). 더 크게 쓸 때는 정수 배로만 키우고 `image-rendering: pixelated`를 켜 주세요.
- 캐릭터·착용·섬장식은 32×32칸, 기준점(발바닥) (16, 30). 착용 그림은 같은 캐릭터 위에 같은 좌표로 겹치면 맞아요.
- 글자가 그림에 찍힌 버튼은 manifest의 `label`에 문구가 있어요.
- 전체 목록과 크기: `manifest.json` · 그림으로 보기: `미리보기.png`
- `99_원본/`은 디자이너용(편집기 파일, @8x)이라 앱에는 넣지 않아요.

## 14_타일 (노션 「도트 디자인 UI & 캐릭터 등」에서 가져옴)

- `@2x.png` = 도트 칸이 깔끔한 그림을 1칸 2px로 맞춘 것(잔디밭·젖은 모래·화산 등).
- `@orig.png` = 512px로 그려져 도트 칸 격자에 맞지 않는 그림(바다·해안가·마른 모래사장). 줄이지 않고 원본 그대로 넣었어요. 앱에서는 64pt로 줄여 쓰거나 도트 칸으로 다시 그려야 해요.
- 해안가는 `coast-<줄>-<번호>`로, 줄 순서(0→4)대로 이어 깔아야 물결이 이어져요(디자인 시스템 규칙).
- 잔디밭·화산은 아직 이름이 정해지지 않아 번호로 두었어요. 위치 이름이 정해지면 바꿔 주세요.
- 노션 원본 파일은 `99_원본/notion-원본/` 에 있어요.
