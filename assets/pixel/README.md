# Pixel assets (기디 교체용)

`constants/pixel-assets.ts`의 `PIXEL_ASSETS`에 이미지를 넣으면
코드 도트 스프라이트 대신 해당 이미지가 표시됩니다.

권장 파일명 예:

- `egg.png`, `sprout.png`, `buddy.png`, `tree.png`
- `house.png`, `pebble.png`, `canola.png`, `seed.png`
- `island.png`, `volcano.png`, `volcano-erupt.png`
- `tangerine.png`, `lock.png`
